# HackAlem AI — Agentic AI для прогноза выработки ВЭС на 24–48 ч

> 🚧 В разработке. Этот README дополняется на каждом этапе.

## Задача
Почасовой прогноз нормализованной выработки двух турбин ВЭС на 24–48 ч.
Прогноз выпускается ежедневно с 31.01.2026 по 28.02.2026. Используются только архивные погодные прогнозы,
доступные на момент выпуска.

## Протокол прогноза и защита от утечки
- В локальный день **D в 10:00** (время станции = время SCADA, **UTC+6**) система выпускает почасовой прогноз на **D+1 и D+2** (48 часов).
  Первый выпуск — 31.01.2026, последний — 27.02.2026.
- Погода берётся **только из архивных прогнозов**, опубликованных до момента выпуска, а не из реанализа (ERA5) или факта:
  - **ECMWF IFS 9 км** — точные прогоны (Open-Meteo *Single Runs API*, архив с марта 2024, 00/06/12/18z);
  - **GFS, ICON, ECMWF 0.25°** — ансамбль (Open-Meteo *Previous Runs API*, значение, спрогнозированное за N суток до срока).
    Мы проверили сравнением с точными прогонами, что `previous_dayN` для часа t = прогон `floor_6h(t) − N суток`.
- Единое правило: строка прогноза доступна в момент `as_of`, только если
  `init_time + задержка_публикации(модель) ≤ as_of` (задержки консервативные: ECMWF 8 ч, GFS и ICON 6 ч).
  Реализовано в `weather/store.py::get_forecast`, покрыто тестами `tests/test_weather_store.py`.
  Для каждого тестового выпуска прогоны сохранены в `outputs/weather/test_issue_runs.csv`.

## Структура
```
config.yaml                    все параметры (координаты, протокол, модели NWP, задержки)
src/hackalem/
  config.py                    загрузка конфига
  timeutils.py                 UTC ↔ время станции, момент выпуска, целевые часы
  data/turbines.py             загрузка SCADA, флаги качества, агрегация в часовые
  weather/openmeteo.py         HTTP-клиент: кэш на диске, ограничение частоты запросов, повторы
  weather/sources.py           загрузка точных прогонов и прогонов за прошлые дни → единый формат
  weather/store.py             архив прогнозов + get_forecast(as_of) без утечки
  weather/issued.py            воспроизведение протокола выпуска на истории (данные для обучения)
scripts/
  run_eda.py                   этап 0: EDA → outputs/eda/
  build_weather_archive.py     этап 1: скачать архив NWP → data/weather/forecast_store.parquet
  check_weather.py             этап 1: часовой пояс, качество моделей, аудит тестовых выпусков → outputs/weather/
tests/                         pytest
data/raw/                      исходные CSV организаторов
data/weather/                  архив прогнозов (в репозитории, чтобы работало без интернета)
```

## Быстрый старт
```bash
pip install -r requirements.txt
pip install -e .
python scripts/run_eda.py
python scripts/build_weather_archive.py   # ~15 мин при первом запуске; повторно — из кэша
python scripts/check_weather.py
pytest -q
```
