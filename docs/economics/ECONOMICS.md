# Экономический эффект прогноза (репетиция на январе 2026)

Суточный план подачи на БРЭ (D+1), цены из `config.yaml`: недовыработка **40 тг/кВт·ч**, перевыработка **18 тг/кВт·ч**, поэтому оптимальный план — квантиль **q* = 0.31** прогноза, а не медиана.
Стоимость небалансов — на **1 МВт установленной мощности за месяц**, факт — SCADA.

|---|---|---|---|
| климатология (без прогноза погоды) | среднее месяц×час | 6,240 | 0% |
| без агента | медиана P50 | 4,007 | 36% |
| без агента | оптимальный квантиль P31 | 2,912 | 53% |

| агент | оптимальный квантиль P31 | 2,640 **←** | 58% |
